# App Builder Workspace (Wolf)

Grok App Builder Workspace — a full-stack Vite + React + TypeScript application with authentication, PWA support, multiplayer capabilities, and an extensive set of AI skills for building games and interactive apps.

## Features

- Vite + React + TypeScript
- Authentication system (email/password + identity gates)
- PWA support
- PGlite / local database
- Multiplayer P2P
- Rich set of skills for 2D/3D game development, UI, assets generation, etc.
- Ready for Vercel deployment

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start development server
- `npm run build` — production build
- `npm run typecheck` — TypeScript check
- `npm test` — run tests

## Project Structure

- `src/` — application source code
- `.grok/skills/` — AI skills and references for building games & apps
- `scripts/` — build and utility scripts
- `server/` — server middleware
- `public/` — static assets
